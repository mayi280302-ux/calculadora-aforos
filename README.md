# Calculadora de Aforos

Calculadora de caudal para aforos de campo:

- **Molinete (cartera de campo):** método de la sección media (ISO 748), para río (orillas en cero) o canal (paredes medidas). Basada en la cartera de campo Cenicaña–CVC.
- **Volumétrico**, **flotador**, **vertederos** (triangular, Francis, Cipolletti) y **canal Parshall**.

Funciona en el navegador, también en el celular, sin instalar nada. Los datos que escribes se guardan solo en tu navegador.
